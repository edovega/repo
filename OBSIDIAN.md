# Obsidian

The repository root can be opened directly as an Obsidian vault. Obsidian is an optional navigation and authoring layer; GitHub remains fully usable without it.

- Use standard Markdown links so that GitHub and Obsidian work together.
- Treat each published item's metadata as the source of truth.
- Keep local workspace state, caches, and personal notes outside version control.
- Do not add private source files, raw research notes, or Drive exports to this public vault.

See [EXPERIENCE-STANDARD.md](EXPERIENCE-STANDARD.md) and [templates/](templates/) before creating content.
