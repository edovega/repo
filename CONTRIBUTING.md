# Portfolio Publishing Guide | Guía de Publicación

This repository is curated by Eduardo J. Vega Arguedas. Contributions, corrections, and reuse are welcome within the boundaries of [SECURITY.md](SECURITY.md).

## Before adding a piece

1. Select a topic for professional value, not merely because it was an assignment.
2. Use one of the templates in [templates/](templates/).
3. Add complete metadata and a clear audience.
4. Rewrite source material in original language; do not copy academic or third-party content.
5. Sanitize examples, data, screenshots, paths, and evidence.
6. Add bilingual versions when the piece is intended for both audiences.
7. Update [CATALOG.md](CATALOG.md) and related area pages.

## Naming

- Directories: lower-case kebab-case, for example `mobile-application-security-audit`.
- Bilingual documents: `topic.en.md` and `topic.es.md`.
- Every item begins with a portal `README.md` and its metadata.

## The test

A visitor should understand the value of an item from its title and first screen, without knowing the course, the author, or the original assignment.
