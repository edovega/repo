# Security Engineering | Ingeniería de Seguridad

This area covers security built into data, networks, software, identities, architectures, and delivery pipelines.

The emphasis is not a tool list. It is design reasoning: what is protected, which trust assumptions exist, how controls are verified, and how technical choices affect resilience and business risk.

**Expected content:** data protection, PKI, network security, Zero Trust, secure software, identity, cloud controls, and architecture reviews.
